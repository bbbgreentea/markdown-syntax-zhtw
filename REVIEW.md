# Review instructions

## Language / 語言

All review output MUST be written in Traditional Chinese (繁體中文, zh-TW):
the review summary, every inline comment, the "Why this was flagged" details,
and the check run summary. Keep code identifiers, file paths and code snippets as-is.

所有 review 內容（摘要、每則 inline 留言、說明細節、check run 摘要）一律使用繁體中文撰寫。
程式碼、變數名稱、檔案路徑維持原文。
